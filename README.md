# ForgeFlow

An AI-powered platform that helps developers plan, build, verify, improve, and deploy software projects.

## Problem Statement
Developers often struggle to organize and complete software projects efficiently. ForgeFlow provides a structured AI-assisted workflow to guide projects from understanding and planning to building, verification, preparation, showcasing, and deployment.

## Technology Stack
React, Node.js, MongoDB, TypeScript, Express

## Features
- **Core project workflow**: Core capability for ForgeFlow
- **User-focused project experience**: Core capability for ForgeFlow

## Project Setup

```bash
# Install all dependencies
npm run install:all

# Run client and server concurrently
npm run dev
```

## Environment Variables
Copy `.env.example` to `.env` and provide required values.
